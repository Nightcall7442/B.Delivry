# Мобильный и web-клиент: композиция

Web (`apps/web`) собран по тем же правилам: `MarketShell` вместо `Page`, классы `.tile` / `.go-field` / `.go-chip` вместо токенов `ui`, палитра и серые из того же пресета Tailwind.

Как собран экран в `apps/customer` после редизайна — чтобы новый экран выглядел как старый без обсуждений.

## Ритм

| Что                                            | Значение                                                                                                                    | Где живёт              |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| Боковые отступы                                | 16                                                                                                                          | `Page` → `s.content`   |
| Зазор между соседями (карточки, тайлы в рейле) | 12                                                                                                                          | `ui.gap`               |
| Внутренний отступ карточки                     | 14                                                                                                                          | `ui.pad`               |
| Между секциями                                 | 24 сверху, 12 до контента                                                                                                   | `SectionHead`          |
| Радиус                                         | карточка 22 (`ui.radius`), тайл/фото-карточка 20, кнопка 18, пилюля 999                                                     | `ui`, `Button`, `Chip` |
| Тень                                           | одна: `shadow.card` (`ui.shadow`); кобальтовое свечение `shadow.glow` только под главной кнопкой и диском корзины           | `@bazar/mobile/theme`  |
| Фон                                            | белый; карточки — серые плитки `color.tile` (#F4F5F7), поля `color.field` (#EFF1F4); теней нет                              | `Page`, `theme`        |
| Цвет                                           | кобальт Регистана `brand500 #3B6BE3` / `brand600 #2C56C4`; шафран — только рейтинг и Plus; красный — только скидка и ошибка | `theme`, пресет        |
| Пиктограммы                                    | одна манера: линейная иконка из `Icons.tsx`; в диске — `Glyph`; эмодзи и 3D — нет                                           | `Page` → `Glyph`       |

## Шрифт

Manrope во всех ролях. `fontWeight` в стиле выбирает начертание сам (`Text` в `@bazar/mobile`): 500 body, 600 semi, 700 bold, 800 display. Заголовки: `display` 24, `section` 19, `title` 17; цены — `price` (табличные цифры); десятичные — `t.qty()` (запятая), деньги — `t.money()`.

## Словарь карточек (и больше ничего)

1. **Фото-плитка** — серая плитка, фото в рамке 16, подпись под фото тёмным. Категории (`CategoryCard`), точки (`StoreCard`), лента (`FeedCard`). Тёмный градиент с белым текстом — только у героев карусели и «Прилавков сейчас».
2. **Белая карточка** (`Card`/`Panel`) — контент на белом с тенью `ui.shadow`: тайл товара, строки заказов, чекаут, отзывы, «Выгода каждый день».
3. **Пилюля** — чипы, теги, бонусы «961 ⓢ», кнопки в шапке (`Round`, над фото — матовая).

Тинтованные плитки (пастель без фото) допустимы только для иконок 3D в пустых состояниях и маленьких строк профиля.

## Порядок главной

1. Матовая шапка-пилюля: приветствие по времени · адрес (или «Указать») · бонусы · колокольчик
2. Поиск с микрофоном (и подсказки под ним, когда набирают)
3. «Базар сегодня» — бегущая лента цен (скидки и свежее), одна строка
4. Баннер активного заказа — только если он есть
5. Карусель героев: праздник (если окно) · утренняя поставка · сезон
6. Категории — 6 фото-карточек, 3 в ряд
7. «Откуда заказать» — рейл фото-карточек точек (реклама первой)
8. «Прилавки сейчас» — сторис: кольца точек, кобальтовое = есть утреннее фото; тап открывает просмотр с продавцом и кнопкой «В точку»
9. «Вы заказывали» (если есть заказы)
10. «Скидки и свежее»
11. «Наборы к столу»
12. «Выгода каждый день» — одна белая полоса из трёх пунктов
13. «Подобрали для вас» — masonry в две колонки, хвост страницы

Правило: одна мысль на секцию, у каждой секции один и тот же `SectionHead`, у рейлов один и тот же зазор 12 и выход за поля (`marginHorizontal: -16`).

## Экраны

- **Товар**: фото во всю ширину под плавающими матовыми кнопками (параллакс), название · рейтинг · цена, факты (кешбэк, доставка), три обещания базара, продавец, описание, отзывы, похожие; липкий степпер + «В корзину · сумма».
- **Точка**: герой «прилавок сейчас», карточка точки, «За прилавком», «Сегодня привезли», чипы, сетка тайлов; липкая корзина.
- **Корзина / чекаут / заказы**: белые карточки с `ui.pad`, липкий футер с растушёвкой; в чекауте порядок «Куда → Списать с баланса → Когда → Оплата → Продавцу → Ваш заказ».
- **Пустые состояния**: `EmptyState` (3D-иконка · заголовок · подсказка · одна кнопка). Загрузка: `Bone`.
- **Ошибки загрузки**: `LoadError` («Не удалось загрузить · Повторить»), pull-to-refresh через `Page onRefresh`.

## Отдача

Каждое нажимаемое — `press.base` + `press.down` (масштаб 0,97; на web — CSS-переход). Добавление в корзину — хаптика (`tap()`), диск корзины подпрыгивает. Фото — `expo-image` с fade-in, `priority="high"` у героя экрана.

## Проверка

Скриншоты web-сборки на 390×844: `scratchpad/shots-redesign.mjs` (все экраны, ~4 мин), контактный лист через PIL. Правило перед отчётом: посмотреть каждый экран на 2× — не верить типчеку.

## Web на телефоне

Тот же словарь, но ритм плотнее, как у маркетплейсов: сетки 8 px (`gap-2`), секции 24 px (`mt-6`), заголовки 18 px; на десктопе — 12 / 32 / 24. Герои на телефоне — карусель со snap (карточка 82 %, следующая подглядывает, точки под ней), на десктопе — бенто 7/12 + 5/12 + плитка сторис. Под героями быстрый ряд пилюль: скидки, наборы, список, подписки, Plus. Кольца сторис подписаны в две строки: точка, под ней базар серым — без многоточий.

## Тёмная тема

Тот же словарь, инвертированный ground: страница `#121615` (зелёно-холодный, не серый), плитка `#1C2120`, поле `#242A29`, «поднятое» (белая кнопка на плитке) `#2C3332`, линии `#2C3332`, чернила `#ECEFEE`. Зелёный бренда не меняется; светлые оттенки (`brand50/100`, `saffron100`) становятся тёмными, тёмные (`brand700+`, `saffron900`) — светлыми. Белым остаётся только то, что лежит поверх фото: пилюли, полоски сторис, текст на градиенте — и там текст фиксированно тёмно-зелёный (`brand.deep`). Web переключается вживую (меню → Тема), мобилка берёт системную тему при запуске.
