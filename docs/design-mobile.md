# Клиенты: язык «базара»

Как собран экран покупателя в `apps/customer` (Expo) и `apps/web` (Next) — чтобы новый экран выглядел как старый без обсуждений. Регистр 5.17–5.22 (кобальт, серые плитки, Manrope везде) заменён целиком; его описание убрано.

## Идея

Покупатель не листает каталог — он идёт по ряду. Фотография ряда (утро или вечер по ташкентскому времени) заполняет экран, на ней лежит всё остальное: люди за прилавками, картонные ценники на кнопках, крафтовые бирки, чеки. У магазина вместо человека — вывеска: доска чернильного цвета с именем сети и часами над фото зала или фасада.

## Словарь

Библиотека приложения — `apps/customer/src/components/bazar/index.tsx`, web — `apps/web/src/components/bazar/{index.tsx,bazar.module.css}`. Имена совпадают.

## Экраны

- **Главная** (`SceneHomeScreen`, `bazar/home.tsx`): приветствие по времени и имени → «Продавцы на месте» (люди, открытые первыми) → «Магазины рядом» (одна вывеска на сеть, филиал — ближайший к адресу) → «Пройтись по ряду» (таблички категорий) → «На прилавках сегодня» (только товары прилавков, утренний привоз первым). Внизу — голосовая строка «Скажите, что нужно» и диск корзины; с товарами — полоса «Оформить».
- **Прилавок** (`StoreScreen`, `bazar/store.tsx`): утреннее фото прилавка фоном (тап — «прилавок сейчас»), человек с его фразой, пилюли рейтинга/времени/доставки, фильтр по полкам, ценники сеткой.
- **Магазин** (`ShopScreen`, `bazar/shop.tsx`, маршрут выбирает `isShopfront`): фото магазина фоном, доска с именем, филиалом и часами, «заказ от» / «бесплатно от», «Как в прошлый раз», «Собрать по списку», поиск по полкам, полки = только категории с товаром (`/categories?storeId=`), товары по 24 с догрузкой на прокрутке.
- **Ряд** (`RowScreen`) и **Карта рядов** (`CategoriesScreen`, `bazar/catalog.tsx`): план базара на крафте — только прилавки; магазины стоят за воротами отдельной рейкой вывесок. Поиск ищет и по магазинам.
- **Корзина** (`CartScreen`, `bazar/cart.tsx`): один чек на точку; «Оформить одной доставкой» — только для прилавков одного базара (`oneTrip`). Подпись: «1 прилавок / 1 магазин · один курьер», «N точек · отдельные доставки».
- **Оформление**: чек с адресом, временем, «Продавцу», «Если чего-то нет» (у магазина по умолчанию «Заменить похожим»), оплатой; тяжёлый заказ пишет строку про авто и надбавку.
- **Заказы, заказ, профиль, вход**: бумажные листы на сцене; вход — «у ворот», код через Telegram или SMS.
- **Пустые состояния и ошибки**: `LoadError` — бумажный листок на булавке с рукописной строкой и «Повторить»; загрузка — `Bone`.

## Отдача

Каждое нажимаемое — `press.base` + `press.down` (масштаб 0,97; на web — CSS-переход). Добавление в корзину — хаптика (`tap()`), диск корзины подпрыгивает. Фото — `expo-image` с fade-in (на web без cross-dissolve), `priority="high"` у фона сцены.

## Web

Тот же словарь в `bazar.module.css`; цвета сцены — CSS-переменные на `.scene` и `.paper-sheet`, не тема сайта. Телефон — как приложение; на ≥768 px полоса «Оформить» становится пилюлей в правом нижнем углу, «узкие» страницы (корзина, оформление, заказы, профиль, вход) — центрированная полоса 640 px, фото точки получает дополнительный скрим сверху (`.photoStall`). Липкие полки магазина — `.shelves`.

## Данные, не выдумки

Температура на бирке — живая с Open-Meteo или её нет; фотографии — свои (`public/photos`, ключи в `PHOTOS`); имена продавцов и магазинов — из сидов; ни одной цифры «для красоты».

## Проверка

Скриншоты web-сборки Expo (:8084) и Next (:3000) на 390×844 через `shoot.py` из scratchpad сессии (логин по OTP на каждый прогон, сиды `bazar.tokens/address/cart/locale`), контактный лист через PIL. Правило перед отчётом: посмотреть каждый экран на 2× — не верить типчеку.
