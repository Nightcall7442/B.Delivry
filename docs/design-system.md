# «Свет купола» — дизайн-система

Одна система для web (`apps/web`), лендинга (`/promo`), приложений (`apps/customer`, `apps/courier`) и кабинета (`apps/admin`). Лендинг открывается под куполом Чорсу — продукт стоит в том же зале: глазурованный гирих над головой, свет из арочных окон утром, гирлянда над рядами вечером. Источник значений — `packages/storefront/src/dome.ts` (`HALL`, `TONE`, `GROUND`, `girih`); web повторяет их в `apps/web/src/styles/globals.css`, приложения берут через `@bazar/mobile` (`theme.ts`).

## 1. Фон — зал, а не цвет

Под каждым экраном, где нет карты и нет фотографии у двери, — зал:

| Слой                                      | Web                                                                            | Приложения               |
| ----------------------------------------- | ------------------------------------------------------------------------------ | ------------------------ |
| купол                                     | градиент `--ground-top → --ground → --ground-deep`                             | `DomeGround`             |
| гирих                                     | `/dome/morning.svg`, `/dome/evening.svg` (route handler, генератор `girihSvg`) | тот же `girih()` в SVG   |
| узор уходит в тень рядов, виньетка, зерно | `--hall-ground`                                                                | `DomeGround` (без зерна) |
| утро: три луча, дышат 16 с                | `--hall-light`, `.hall::after`                                                 | `DomeGround` → `Morning` |
| вечер: гирлянда, мерцает 6 с              | `:root[data-hall='evening']`                                                   | `DomeGround` → `Evening` |

- Web: класс `hall` на самом внешнем элементе страницы (`<main className={\`hall ${s.scene}\`}>`); свет зала ставит `THEME_BOOT` до первого кадра (`data-hall`на`<html>`), по ташкентскому часу — `isEvening` в storefront.
- Приложения: `<DomeGround />` первым ребёнком экрана, контент после. Своих градиентов «ночи» больше нет.
- Фото остаётся там, где оно — дверь места: вход в базар (фото рядов во весь экран), прилавок и магазин (их собственное фото — верх зала, растворяется в купол маской на web), корзина и оформление (фото прилавка едва видно наверху). Скримы над фото ведут в цвет земли: web `rgb(var(--ground-rgb) / a)` / `--ground-deep-rgb`, приложения `alpha(GROUND[hall].deep, a)`.
- `prefers-reduced-motion` / «Уменьшить движение» — свет стоит.

## 2. Палитра: шесть цветов

| Имя           | Значение  | Роль                                        |
| ------------- | --------- | ------------------------------------------- |
| Бирюза купола | `#123A3A` | земля утром                                 |
| Лазурит       | `#0E1A33` | земля вечером, тёмная тема                  |
| Охра изразца  | `#E39B2F` | акцент: капитель, линейки, выбранный ценник |
| Гранат        | `#9E2A2B` | единственное, что является кнопкой          |
| Крем бумаги   | `#F4EFE4` | бумага: листы, чеки, ценники                |
| Чернила       | `#2B1B0E` | текст на бумаге                             |

Всё остальное — производные (`TONE`): `creamLight #FBF1DE` (текст на земле), `creamMuted #D9C7A6`, `ochreLight #F2C56B` (охра текстом на земле), `kraft #EAD8B2`, `paperEdge #C9B99A`, `inkSoft #6A5A44`, `pomegranateDeep #7E1F21`, `board #16213D` (доска над дверью магазина), глазури `turquoise`, `cobalt`. Новый hex в коде — только если это производная, записанная в `TONE` и в `globals.css`.

Web-переменные: `--dome --lapis --ochre --ochre-light --pomegranate --pomegranate-deep --paper --cream --cream-muted --kraft --paper-edge --ink-paper --ink-soft --board --ground --ground-rgb --ground-top --ground-deep --ground-deep-rgb`. Старые `--night`, `--night-rgb`, `--saffron`, `--saffron-light` не используются. Внутри страниц-сцен Tailwind-нейтрали держат светлые значения (бумага всегда светлая).

Тёмная тема (web `data-theme='dark'`, приложения `isDark`) — лазурит, не коричневый. Приложение курьера всегда светлое (`userInterfaceStyle: light`): его бумага не бывает тёмной.

Ошибки — гранат (`danger` = гранат на бумаге, `pomegranateLit #D9767A` на тёмном), отдельного красного нет. Красные чернила кассы в чеке — суммы, итог, штамп. Счётчики (бейджи) — охра с чернилами.

## 3. Типографика: два голоса

- **Alegreya** — то, что называет: заголовки, имена, приветствие, названия в чеке, «Оформить». Italic — реплика (девиз продавца, строка «Что на ужин?», вечернее приветствие, бирка «Чорсу · утро»).
- **Manrope** — то, чем пользуются: интерфейс, подписи, поля ввода, чипы, суммы в чеке, кнопки-ссылки.
- **Caveat** — только рука продавца на картонном ценнике (`.sign`/`Sign`: название, цена, реплика на ценнике). Больше нигде: не в полях, не в чипах, не в чеках, не в ссылках, не в бирках, не в табличках рядов.
- Roboto удалён.

Шкала — ничего между шагами:

| Шаг      | Размер / строка | Web                                                             | Приложения       |
| -------- | --------------- | --------------------------------------------------------------- | ---------------- |
| caption  | 12 / 16         | `--fs-caption`                                                  | `scale.caption`  |
| body     | 14 / 20         | `--fs-body`                                                     | `scale.body`     |
| lead     | 17 / 24         | `--fs-lead`                                                     | `scale.lead`     |
| title    | 22 / 26         | `--fs-title`                                                    | `scale.title`    |
| headline | 30 / 34         | `--fs-headline`                                                 | `scale.headline` |
| display  | 44 / 46         | `--fs-display`; приветствие на широком окне `--fs-hero` (44→64) | `scale.display`  |

Цифры в ценах, суммах, количествах, чеках — табличные (`font-variant-numeric: tabular-nums` / `fontVariant: ['tabular-nums']`). Капитель одна: Manrope 800, 12 px, разрядка 0.14em, прописные, `--ochre-light` на земле (`.eyebrow` в globals, `Eyebrow` в приложении), `--ink-soft` на бумаге.

## 4. Материалы с иерархией

Сверху вниз: **изразец** (земля) → **стекло** (то, что плавает над землёй: пилюли, поиск, голосовая строка, шапка при прокрутке, липкие полки) → **крафт** (разделы: бирка, таблички рядов, план рядов, ярлыки) → **бумага** (карточки, листы, чеки, ценники) → **чернила** (текст).

- Стекло одно: `--glass` + кромка `--glass-edge` + `--glass-blur` (приложения: `alpha(GROUND[hall].base, 0.55)`, кромка `rgba(251,241,222,0.22)`). Липкие полосы над землёй — стекло, не сплошная заливка.
- Тень одна: `--shadow` (`0 12px 28px` цветом глубины земли) / `shadow.paper`. Всё, что лежит на бумаге, лежит плоско — кнопки внутри листа и шторки тоже. Гранатового свечения под кнопками больше нет.
- Углы три: бумага `--radius-paper` 6 px / `radius.paper` (листы, чеки, ценники, поля, шторка над картой); фото `--radius-photo` 14 px / `radius.photo`; пилюли 999 (кнопки, чипы, стекло). Вывеска магазина — бумага по углам.
- Неактивная кнопка — сплошная пилюля цвета кромки бумаги с текстом `inkSoft`, никогда не полупрозрачная; причина пишется на ней (до двух строк).
- Зубчатый край — только у чека. Булавка — только у ценника. Табличка ряда — крафт без булавки, Manrope капителью.

## 5. Свет и фото одной камерой

- Каждое фото — через один грейд: web `.photo-grade` (фильтр `--photo-grade`, тёплый свет сверху слева, виньетка, зерно); приложения — `Photo` (грейд по умолчанию) или `<PhotoGrade />` последним ребёнком рамки фото.
- Кадр: товар 4:5, человек 3:4. Логотипы и карты — без грейда.
- Движение только физическое и сдержанное: ценник качается на булавке, когда товар ложится в корзину; чек выезжает из принтера при появлении; лучи дышат. Никаких появлений ради появлений. Всё выключается при «Уменьшить движение».
