# Roadmap Bazar Delivery

Обновлено: 2026-09-13. Приоритет = (влияние на выручку/удержание × заметность для рынка) ÷ усилие, с учётом зависимостей. Номера фич — из списка 60 (см. обсуждение), ★ — «делает продукт заметно дороже».

## Принцип

Ни одна фича не считается сделанной, пока её нельзя показать на реальном заказе с реальным курьером. Поэтому первые три недели — только фундамент, без «маркетинговых» фич. Дальше каждая волна заканчивается измеримым результатом, а не списком экранов.

## Что сознательно отложено

Гостевой заказ (32) — OTP занимает 20 секунд, а привязка к покупателю нужна для всего остального. Виджет (40), стрики (22), персональные цены (23) — после того как появятся данные о повторных покупках. Температурный трек (6) — пока нет датчиков в сумках.

## Как читать сроки

Недели считаны для одного фулл-стек-разработчика в паре с AI-агентом при готовом бэкенде. Волна 0 не сжимается — это интеграционные работы с чужими песочницами (Eskiz, Payme, Click). Волны 1–2 параллелятся с маркетингом: пока идёт разработка, договариваемся с продавцами Чорсу и Алайского и снимаем контент.
